# Samuel Cotrim

Versão estática do site, preparada para GitHub Pages. Para abrir no computador,
abra o arquivo `index.html` no navegador.

## GitHub Pages

1. Envie o conteúdo desta pasta para a raiz do repositório, incluindo o
   `.nojekyll`, o `index.html` e as pastas de imagens.
2. Nas configurações do repositório, abra **Pages**. Selecione **Deploy from a
   branch**, a branch onde você colocou os arquivos e a pasta **/(root)**.
3. O endereço do site aparecerá na mesma tela após o deploy.

O site no GitHub Pages pode ficar público. Confira a visibilidade antes de
ativar o serviço. Esta versão leva somente as matérias publicadas. O painel e
os rascunhos ficam na instalação local.
